History
=======

1.9.0 (2025-12-14)
------------------

* Add Ctrl+C/Ctrl+V to copy and paste bounding boxes across images with visual preview
  添加 Ctrl+C/Ctrl+V 跨图像复制粘贴边界框功能，带可视化红色预览
* Add Ctrl+Shift+V to copy all boxes from previous image
  添加 Ctrl+Shift+V 从上一张图像复制所有边界框
* Add Q key to quickly delete hovered shape
  添加 Q 键快速删除鼠标悬停的形状
* Add Ctrl+Z to undo last 20 deleted shapes
  添加 Ctrl+Z 撤销最近 20 次删除操作
* Add double-click on empty area to fit window
  添加双击空白区域适应窗口功能
* Add double-click on shape to edit label
  添加双击形状编辑标签功能
* Swap mouse wheel behavior: wheel to zoom, Ctrl+wheel to scroll
  交换鼠标滚轮行为：滚轮缩放，Ctrl+滚轮滚动
* Add Ctrl key modifier to disable vertex selection for easier box dragging
  添加 Ctrl 键禁用顶点选择，便于拖动小目标框
* Optimize hover detection to prioritize smallest containing shape
  优化悬停检测，优先选择最小的包含形状
* Increase scroll speed by 3x
  滚动速度提升 3 倍
* Show vertices only when hovering over shapes
  仅在鼠标悬停时显示顶点
* Remember zoom level and scroll position when switching between images
  切换图像时记忆缩放级别和滚动位置
* Change border colors to fully opaque for better visibility
  边框颜色改为完全不透明，提升可见性
* Add configurable line width setting (DEFAULT_LINE_WIDTH)
  添加可配置的线宽设置 (DEFAULT_LINE_WIDTH)
